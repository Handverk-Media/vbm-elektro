# 03 · ICP og kundespråk

**Shift kundestandard · VBM Elektro AS · v1.0 · 05.08.2026**

Hvem VBM skriver til, hva som utløser at de tar kontakt, hva som stopper dem — og de faktiske ordene de bruker. Skal du skrive en overskrift, hentes ordene herfra.

---

## 01 · Sammendrag

To målgrupper med to helt ulike frykter. Privatkunden er redd for å bli lurt. Næringskunden er redd for å bli forsinket. Ingen tekst kan snakke til begge samtidig — hver side må velge én.

All aktivitet i dag går mot privat. Næring er definert i konseptdokumentet, men vi har ingen data: ingen annonsering, ingen henvendelser, ingen referanser. Behandle den som hypotese.

---

## 02 · Primær målgruppe — Privat (81 % av annonseforbruket)

### Huseieren som frykter å bli lurt

| | |
|---|---|
| Kundetype | Boligeier i enebolig, rekkehus eller leilighet med egen p-plass. Betaler selv. |
| Geografi | Drammen, Asker og Bærum. Oslo sekundært. |
| Livssituasjon | Har kjøpt elbil, skal pusse opp, eller skal selge bolig. |
| Kunnskapsnivå | Kan ikke faget. Har lest litt, nok til å være skeptisk. |

| | |
|---|---|
| Typiske behov | Få montert ladeboks. Få en småjobb gjort uten at det blir et prosjekt. Få vite om anlegget tåler mer. |
| Typiske oppdrag | Elbillader med egen kurs. Nytt sikringsskap. Punkter og lys ved oppussing. Varmekabler. Feilsøking når noe slår ut. |
| Hva utløser behovet | Ny elbil bestilt, leveres om noen uker. Sikringen slår ut. Bad eller kjøkken skal pusses opp. Boligen skal selges og papirene mangler. |
| Hva de ønsker å oppnå | At problemet er borte og at de slipper å tenke på det igjen. Bilen full hver morgen. Én pris, én dag, ferdig. |
| Hva de ønsker å unngå | Regningen som blir det dobbelte. Å måtte purre. Å bli behandlet som om spørsmålene deres er dumme. |
| Hva de bekymrer seg for | Å bli lurt uten å merke det, fordi de ikke kan faget. Brann. At tillegg dukker opp etter at jobben er gjort. |
| Hva som hindrer kontakt | De vet ikke om det koster 8 000 eller 30 000. De vet ikke om befaring koster noe. De vet ikke hva de skal spørre om. |
| Hva de vurderer | Om prisen står oppgitt. Om noen svarer. Om firmaet finnes på ordentlig. Om anmeldelsene er greie. |
| Hva som skaper tillit | Konkrete tall. Bilder av ekte jobber. En forklart prosess. At noen tør si «det gjør vi ikke». |
| Hva som skaper usikkerhet | «Ta kontakt for pris». «Fra»-priser uten vilkår. Arkivbilder. Ingen adresse eller organisasjonsnummer. |
| Alternativer de vurderer | Kjedeaktørenes kampanjepris. Anbudsportal. Strømselskapets pakke med finansiering. Elektrikeren i familien. |
| Hvordan de finner leverandør | Google, fra mobil, ofte om kvelden. Deretter Google Maps og anmeldelser. Sjelden sosiale medier. |
| Hvordan beslutningen tas | Åpner to–tre sider, velger den som svarer tydeligst og er lettest å ringe. Ofte samme kveld. Den som svarer først, vinner ofte. |

## 03 · Sekundær målgruppe — Næring (⚠ hypotese, ingen data)

### Forvalteren og entreprenøren som frykter forsinkelse

| | |
|---|---|
| Kundetype | Driftsleder, eiendomsforvalter, prosjektleder, styreleder i borettslag. |
| Geografi | Samme nedslagsfelt. Ofte flere bygg i samme portefølje. |
| Situasjon | Har ansvar for drift eller framdrift, og bruker andres penger. |
| Kunnskapsnivå | Kjenner NEK 400 og NS-standardene. Har sett ordet «rammeavtale» hundre ganger. |

| | |
|---|---|
| Typiske behov | Rask utrykning ved driftsstans. Ladeanlegg beboerne krever. Utbedring av avvik. En leverandør som svarer. |
| Hva utløser behovet | Beboere krever ladepunkt. Eksisterende elektriker leverer ikke. El-kontroll har avdekket avvik. En underentreprenør har falt fra. |
| Hva de ønsker å oppnå | Forutsigbar drift. Papirene i orden før noen spør. Ett anlegg som kan bygges ut trinnvis. |
| Hva de bekymrer seg for | Forsinkelse som stopper overtakelsen. Dokumentasjon som ikke kommer. Personlig ansvar hvis det brenner i garasjeanlegget. |
| Hva som hindrer kontakt | Usikkerhet om et lite firma har kapasitet. Ingen referanser fra tilsvarende bygg. Ingen navngitt kontaktperson. |
| Hva som skaper tillit | Dokumentert erfaring fra lignende anlegg. Konkrete responstider. Beskrevet dokumentflyt. Svar på e-post samme dag. |
| Alternativer de vurderer | De store lokale elektroentreprenørene. Rammeavtalen de allerede har. Leverandører av systemlading som selger direkte til styret. |
| Hvordan beslutningen tas | Uker, ikke timer. Ofte via et styre eller en innkjøpsprosess. Tilbud fra to–tre. Pris er sjelden avgjørende alene. |

## 04 · Prioritering

**Vi prioriterer:**
1. Huseier som skal ha ladeboks montert. All annonsering peker hit.
2. Huseier med en avgrenset jobb som vil vite prisen først.
3. Boligselger og huseier med gammelt anlegg — elsjekk og sikringsskap.

**Vi prioriterer ikke ennå:**
- Borettslag og sameier — til systemlading er avklart
- Store entrepriser og nybygg — kapasitet ukjent
- Rene smarthusprosjekter — ingen bevis, annet salg
- Kunder som handler kun på laveste pris

✗ Hvilke oppdrag VBM selv helst unngår, er ikke oppgitt. Det avgjør hvilke søkeord vi skal utelukke i annonsekontoen — og bør avklares.

## 05 · Kjøpssituasjoner

| Situasjon | Beskrivelse |
|---|---|
| Akutt behov | Sikringen har slått ut, noe har sluttet å virke, det lukter svidd. Søker «elektriker» pluss sted, ringer den første som svarer. Ingen leser en tjenesteside her — de trenger et nummer og en beskjed om når noen kan komme. |
| Planlagt behov | Elbil er bestilt, bad skal pusses opp. Uker til måneder på seg. Leser, sammenligner, ber om tilbud. Dette er hovedsituasjonen for VBM. |
| Undersøkende fase | «Hva koster det å installere elbillader?» De vet ikke om det er 8 000 eller 30 000, og orienterer seg. Her vinnes de av et ærlig svar, ikke av et skjema. |
| Sammenligningsfase | Har to–tre priser. Ser etter hva som er inkludert og hva som ikke er det. Den som er tydeligst på tillegg, vinner — også når prisen er høyere. |
| Klar til å kjøpe | Søker på merkenavn: «zaptec go ferdig montert». Har valgt produktet, mangler montør. Kortest vei fra søk til avtale — og den mest lønnsomme trafikken VBM har. |

## 06 · Beslutningskriterier

| Kriterium | Hva det betyr her | Vekt |
|---|---|---|
| Pris | Ikke lavest, men kjent. Kunden vil kunne regne på det før hun ringer. | Høy |
| Responstid | Den som svarer først, får ofte jobben. Dette er VBMs valgte posisjon. | Høy |
| Trygghet | At firmaet finnes på ordentlig, er registrert og sertifisert. | Høy |
| Anmeldelser | Sjekkes nesten alltid før man ringer. VBM har ingen — dette er en reell blokkering. | Høy |
| Kvalitet og dokumentasjon | Samsvarserklæring i Boligmappa. Betyr mest for de som skal selge bolig. | Middels |
| Geografi og lokal tilhørighet | «Lokal elektriker» betyr både rask fremmøte og at noen kan holdes ansvarlig. | Middels |
| Erfaring og kompetanse | Konkurrentenes viktigste argument — men lite dokumenterbart for VBM ennå. | Middels |
| Tilgjengelighet | Åpningstider og døgnvakt. VBM skal ikke konkurrere her før bemanningen er kjent. | Lav |

## 07 · Kundespråk

**Ordrette søk — juni 2026:** pris elbillader ferdig montert · zaptec go ferdig montert · installere elbillader pris · elbil lader hjemme · elektriker timepris · hva koster det å installere elbillader · elbillader ferdig montert pris · ladeboks til bil · hva koster en elektriker · hjemmelader · zaptec montering

| | |
|---|---|
| Slik beskriver de problemet | «Jeg har fått elbil og har ingen lader.» «Sikringen slår ut hver gang jeg bruker ovnen.» «Anlegget er fra åttitallet, jeg vet ikke om det holder.» |
| Slik beskriver de ønsket resultat | «Ferdig montert.» «At det bare virker.» «At jeg vet hva det koster på forhånd.» «At bilen er full om morgenen.» |
| Slik beskriver de en god leverandør | «Han kom da han sa han skulle komme.» «Ryddig etter seg.» «Sa fra før han gjorde noe ekstra.» «Prisen ble som avtalt.» |
| Slik beskriver de en dårlig erfaring | «Regningen ble det dobbelte.» «Fikk aldri svar.» «Måtte purre tre ganger på papirene.» «Han dukket ikke opp.» |

⚠ Formuleringene over er rekonstruert fra søkeatferd og bransjekunnskap, ikke sitert fra ekte kunder. De skal erstattes med ordrette sitater så snart anmeldelser eller intervjuer finnes.

**Spørsmål målgruppen stiller:**
- Hva koster det å få montert en elbillader hjemme — alt inkludert?
- Hvor mange meter kabel er med i prisen, og hva koster det utover?
- Trenger jeg overspenningsvern, og kommer det i tillegg?
- Har sikringsskapet mitt nok kapasitet — og hvordan finner dere ut av det?
- Koster befaring noe hvis jeg ikke bestiller likevel?
- Hvor lang tid tar jobben, og når kan dere komme?
- Hva er timeprisen deres?
- Får jeg papirene i Boligmappa, og må jeg be om dem?
- Kan dere montere laderen jeg allerede har kjøpt?
- Kjører dere hit — og koster kjøringen noe?

| Slik sier kunden det | Fagord som må forklares |
|---|---|
| ladeboks · hjemmelader · lader hjemme | ladestasjon · ladepunkt · Mode 3 |
| ferdig montert | egen kurs · jordfeilvern type B |
| hva koster det | overspenningsvern |
| sikringsskapet | lastbalansering |
| papirene | samsvarserklæring |
| at det ikke slår ut sikringen | NEK 400 · delnorm 722 |
| noen som kan komme og se på det | befaring |

**Regelen:** kundens ord i overskriften, fagordet i setningen etter. «Ladeboks ferdig montert — egen kurs, jordfeilvern og samsvarserklæring inkludert.» Da finner de siden, og de stoler på den når de har funnet den.

## 08 · Kundeomtaler

✗ Ingen omtaler av VBM finnes. Ingen systematisk gjennomgang av konkurrentenes omtaler er gjort.

Anbefalt neste steg: les 30–50 Google-anmeldelser av lokale elektrikere og noter de gjentatte temaene. Det er den raskeste veien til ekte kundespråk — og til å vite nøyaktig hvilke løfter som treffer i dette markedet.

## 09 · Viktigste innsikter

1. Målgruppen søker på pris, ikke på elektriker. Prisspørsmålet er inngangen til alt annet.
2. Frykten er ikke å betale for mye. Den er å bli behandlet dårlig uten å merke det.
3. Sju av ti kommer fra mobil, ofte om kvelden. Ring-knappen må være ett trykk unna hele veien ned.
4. Den som svarer først vinner ofte. Derfor er CRM-koblingen ikke en teknisk oppgave, men en salgsoppgave.
5. Uten anmeldelser mangler VBM det ene beviset målgruppen alltid sjekker. Anmeldelsesflyten er derfor viktigere enn mer annonsebudsjett.
